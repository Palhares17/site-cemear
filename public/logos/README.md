## Qualidade

São JPEGs exportados do WhatsApp, sem transparência: o fundo de cada logo
está impresso na imagem (Grupo Aterpa em cinza, Ápia em azul, Zummit em
cinza-claro). Se quiser a faixa visualmente uniforme, peça aos parceiros os
PNGs originais com fundo transparente e substitua os arquivos mantendo os
mesmos nomes — o HTML não precisa mudar (só a extensão, se virar `.png`).

Exibição: altura máxima de 48px (`max-h-12`).
